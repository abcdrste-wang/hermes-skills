# 12306 余票查询

**无需登录，直接查。**

## 用法

```bash
# 查特定线路
python3 ~/.hermes/scripts/12306_cli.py search "北京" "上海" 2026-06-10
python3 ~/.hermes/scripts/12306_cli.py search "广州南" "深圳北" 2026-06-10 --type G
```

可选参数：
- `--type G` = 只看高铁, `D` = 动车, `C` = 城际
- 车站名支持模糊匹配（"北京南"、"北京西"）

## 通过聊天

直接跟我说：`查广州南到深圳北 明天的高铁`
或者：`12306 北京到上海 下周三`

## 查车站代码

```bash
python3 ~/.hermes/scripts/12306_cli.py stations 广州
```

## 输出内容

每趟车显示：车次、出发/到达时间、历时、出发/到达站、各座位余票

注意：票价金额需登录才能获取，当前仅显示余票数量（"有"/数字/"无"）
