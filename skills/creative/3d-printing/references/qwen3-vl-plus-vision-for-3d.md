# Qwen3-VL-Plus: 3D建模专用视觉模型

## 发现背景

2026-06-08 用户在3D建模会话中发现 GLM-4v-Flash 在三维几何推断上存在严重幻觉（报告"没有制退器"但图中明显可见），于是搜索替代方案并找到阿里百炼的 Qwen3-VL-Plus。

## 关键优势

Qwen3-VL-Plus 被阿里官方广告宣传为具备**空间感知（空间感知）**能力——这是专为3D场景设计的，适合：
- 3D模型参考图的多角度理解
- 武器/角色/机械的部件定位和识别
- 空间布局和比例关系推断

## 定价

- ¥2.5-5/M tokens（文本输入 + 视觉理解）
- 比 GLM-4v-Flash（免费）贵但不贵
- 用户余额 ¥91.06

## 配置方式

需要 DashScope API Key（格式：`sk-sp-xxx`，注意不是普通的 `sk-xxx`），通过环境变量设置：

```bash
# config.yaml
providers:
  vision:
    provider: alibaba
    model: qwen3-vl-plus
```

对应 API Key 在 `.env` 中：
```
DASH_SCOPE_API_KEY=sk-sp-xxx
# 或者
ALIBABA_API_KEY=sk-sp-xxx
```

## 注意事项

- 阿里百炼 API Key 与 DeepSeek API Key 是两套不同的系统
- sk-sp-xxx 格式的 Key 只能用于百炼的商用模型（Qwen3-VL-Plus、Qwen3.7-Plus 等），不能用于 DeepSeek
- 不可用于精确尺寸测定——视觉模型再怎么好也只能做定性分析，不能替代数显卡尺

## 已确认的局限性 (2026-06-09 会话)

### 1. 孤立渲染图的类别幻觉

**现象**: 当被要求分析一张纯模型渲染图（蓝色线框+白底，无参考图上下文），Qwen3-VL-Plus 将 FFAR1 科幻步枪误认为 "GPCR蛋白结构"（游离脂肪酸受体1，也正是FFAR1的生物学术义）。这是由于视觉模型缺乏上下文时，会用自己的知识库来补全"看起来像什么"。

**结论**: **绝对不能单独发送模型渲染图给 Qwen3 要求评估。** 必须同时提供原始参考图。

**正确用法**:
```
❌ 错误: "这张渲染图看起来像枪吗？"
✅ 正确: "左边是原始参考图，右边是我的重建版本——请比较两者的轮廓是否一致"
```

### 2. 点云参考图方向判断不稳定

**现象**: 同一张 Bambu AI 点云参考图（黄色点群，黑底），Qwen3-VL-Plus 在不同调用中给出了相反的方向判断——第一次说"枪口朝上"，第二次说"枪口朝下"。这是因为稀疏点云缺乏清晰的朝向信号。

**根因**: 点云在空间中是离散的，没有连续表面。观察者只能根据点云密度分布推测朝向，而推断结果受提示措辞的微妙影响。这不是模型bug，是**数据的固有限制**。

**应对策略**: 
- 不依赖单次"朝上/朝下"判断
- 用前视图/顶视图辅助确认方向
- 让用户自己看图确认方向（"枪口在上还是下？"）

### 3. 多轮比较时的尺度漂移

**现象**: 在连续多轮评估中（v5对比v6对比v7），视觉模型会逐渐"忘记"原始参考图的标准，趋向于相对评价（"看起来比上一轮好"）而非绝对评价（"和参考图的相差多少"）。

**策略**: 
- 每次评估都重新附带原始参考图
- 使用叠加对比图（黄色参考 + 蓝色重建半透明叠加）代替分开展示
- 要求模型给出具体的覆盖百分比或分数，并说明依据

### 4. 内部特征（空洞/孔洞）容易遗漏

**现象**: 参考图腰部有两个左右对称的椭圆形空洞，连续多轮 vision 评估都没有指出这个特征，直到被明确问"腰部是否有椭圆形空洞"时才确认。

**应对**: 评估时用 checklist 覆盖所有预期特征，不能依赖 vision 主动发现。对于参考图中的空洞/孔洞/镂空特征，必须显式提问。

## 建议的渲染评估流程

```
1. 渲染模型 + 原始参考图合并为同一张对比图
   ┌──────────┐  ┌──────────┐
   │ 原始参考图  │  │ 重建模型  │
   │ (黄色点云) │  │ (蓝色线框)│
   └──────────┘  └──────────┘
   
2. 发送叠加对比图（黄色参考+蓝色半透明叠加）
   - 青色/绿色区域 = 对齐良好
   - 黄色暴露区域 = 重建缺失
   - 蓝色外露区域 = 过重建

3. 要求评估:
   a) 蓝色覆盖了多少黄色区域（%）？
   b) 最大偏差在哪？
   c) 具体哪些特征没对上？
```
