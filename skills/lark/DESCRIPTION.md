# Lark/Feishu CLI Skills

飞书官方 CLI 工具 26 个 AI Agent Skill，覆盖 18 个业务域。

## 依赖

需要安装 `lark-cli`：
```bash
npm install -g @larksuite/cli
```

然后绑定并授权：
```bash
lark-cli config bind --source hermes --identity user-default
lark-cli auth login --recommend
```
