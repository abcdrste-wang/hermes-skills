# 用户偏好的结论先行输出模板

## 背景

本用户明确偏好「结论先行」的输出格式。此模板捕捉了用户自己写的范文结构，适用于比价、工具对比、方案分析、决策建议等所有对比/分析/推荐场景。

## 通用模板

```
结论先说：{核心结论}

下面用和 {B} 对比的方式讲清楚：

一、{主题或场景}？能不能「{核心问题}」？
{直接回答：能/不能}，{一句话展开}
{2-3 句详细分析}

二、和 {B} 的关键区别（你最关心的）
1. {A}：{A 的优势/特点}
   - {特点1}
   - {特点2}
2. {B}：{B 的情况/限制}
   - {限制1}
   - {限制2}

三、现实结论（一句话）
- {A} = {一句话定位}
- {B} = {一句话定位}

四、你该怎么选
- {场景1} → {选择 A}
- {场景2} → {选择 B}
{可选：开放式询问是否要具体步骤}
```

## 真实范文（用户写的 Hermes vs OpenClaw 对比）

```
结论先说：Hermes 理论上能做"比价"这件事，但它不像 OpenClaw 那样开箱即用、专门为淘宝/京东/拼多多比价做好了封装；你要自己拼浏览器+登录+反爬，门槛高很多。

下面用和 OpenClaw 对比的方式讲清楚：

一、Hermes 能不能"登录三大平台 + 比价"？
能，但要自己搭，不是自带功能。
Hermes 本质是一个通用 AI 调度框架：
- 它自带浏览器自动化能力（基于 Playwright / 可配 Camoufox）
- 可以写 Skill：打开淘宝 → 搜索商品 → 抓价格 → 切京东 → 抓价格 → 对比输出
- 登录逻辑和 OpenClaw 一样：
  1. 第一次你手动扫码/输验证码
  2. Hermes 保存 Cookie/指纹
  3. 后续复用登录态访问商品页

二、和 OpenClaw 的关键区别（你最关心的）
1. OpenClaw：开箱即用、专门做电商比价
   - 内置淘宝/京东/拼多多专用适配（包括淘宝桌面版授权）
   - 浏览器指纹、Cookie 目录、反爬策略预设好
   - 你一句话："帮我比价"，它直接跑完，不用写代码
2. Hermes：通用型，要自己写/装 Skill
   - 没有官方"淘宝京东拼多多比价"Skill（至少目前没有）
   - 你要：装浏览器插件、写/找一个 Skill、自己调参数
   - 更像：给你一套积木，自己拼出比价机器人

三、现实结论（一句话）
- OpenClaw = 成品比价工具
- Hermes = 万能工具箱

四、你该怎么选
- 你只想一键比价、少折腾：用 OpenClaw。
- 你想自己定制流程、顺便做别的自动化：用 Hermes，自己写个比价 Skill。
```
