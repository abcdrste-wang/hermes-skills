# 比价结果输出格式化规范

## 背景

`taobao_jd_pricer.py` 的原始输出包含原始 HTML 提取数据，有很多噪音（重复、空行、推广链接、换行拆分）。Agent 必须做 AI 后处理才能交付给用户。

## 用户消费偏好

- **结论先行** — 先给对比表/结果，再给详细分析。不要先讲过程再给结果。
- **算单位价格** — 不同规格（4桶 vs 8桶 vs 6箱）必须折算到"单桶价"才能比
- **给推荐** — 给出 1-2 个明确建议（"如果量小选X，量大选Y"），不要罗列全部选项
- **去重** — 相同价格+相同店铺+相同规格的商品只保留一条

## 输出模板

### 模板：两家平台都有数据

```
## 📊 {商品名} — 比价结果

| # | 平台 | 商品 | 单位价 | 总价 | 销量 | 店铺 |
|---|------|------|--------|------|------|------|
| 1 | 淘宝 | ... | ¥X.XX/桶 | ¥XX.X | N笔 | XXX |
| 2 | 京东 | ... | ¥X.XX/桶 | ¥XX.X | N笔 | XXX |

**推荐：** {一句话建议}
```

### 模板：只有一家有数据

```
## 📊 {商品名} — 比价结果

**京东：** 被风控拦截（账号级封禁，等待自动解除）

**淘宝搜索结果：**

| # | 商品 | 单位价 | 总价 | 销量 | 店铺 |
|---|------|--------|------|------|------|
| 1 | ... | ¥X.XX/桶 | ¥XX.X | N+人付款 | XXX |

**选哪个划算？** 算单桶价：
- **#1** ¥XX.X / X桶 = ¥X.XX/桶 ← 最优
- **#2** ¥XX.X / X桶 = ¥X.XX/桶

**结论：** {按场景推荐}
```

## 常见数据清洗操作

### 1. 解析标题中的规格

从标题提取规格信息（如 `5.5L×4桶`、`5.5Lx8桶`、`5.5L*4桶×6箱`）：
- `×`、`x`、`X`、`*` 都是乘号变体
- 有 `箱` 字的要拆箱再算（如 `4桶×6箱` = 24桶）
- 用于计算"单桶价"

### 2. 合并分行价格

脚本输出价格可能被换行拆分：
```
¥
71
.91
```
→ 合并为 `¥71.91`

### 3. 跳过无效条目

过滤条件：标题为空、价格为空、店铺为空 → 跳过。

### 4. 推广链接处理

`click.simba.taobao.com`（淘宝直通车/推广链接）：
- 不可直接访问
- 尝试从同一条目的其他字段提取直链（`store.taobao.com` 或 `item.taobao.com` 开头的URL）
- 若无法提取，标注"推广链接"而非直接给出不可点链接

### 5. 去重逻辑

两条商品判定为重复的条件（全部匹配）：
- 标题完全一致
- 价格完全一致
- 店铺名完全一致

保留第一条出现的即可。

### 6. 真实输出中常见的具体噪音（Agent 必须清理）

以下是从真实运行中观察到的输出噪音：

| 噪音 | 示例 | Agent 操作 |
|------|------|-----------|
| 完全重复的行 | 商品 #1 和 #2 内容完全一样 | 保留一条，删除其他 |
| 空白条目 | 标题、价格、店铺全部为 N/A | 删除整行 |
| 部分空白条目 | 只有标题有值，价格和店铺为 N/A | 删除 |
| 推广链接伪装成直链 | `https:https://click.simba.taobao.com/...` | 标注"推广链接"，从同条目其他字段提取直链 |
| 换行拆分价格 | `¥\n71\n.91` | 合并为 `¥71.91` |
| 金额后面带文字 | `¥71.91\n优惠后` | 提取 `¥71.91` 作为价格 |
| 店铺名包含前缀 | `回头客1000万\n天猫超市` | 取最后一行作为真实店铺名 |
| 多人付款标记 | `300+人付款` | 作为销量参考值 |
| 地区信息夹杂 | `北京   店铺: 回头客1万\n中唐嘉品企业店` | 提取地区到独立字段，店铺取最后一行 |

### 7. 输出顺序

按单桶/单位价格升序排列（最便宜排第一），而非脚本输出顺序。将最划算的选项标记为 ← 最优。

## 真实案例参考

**2026-06-07 娃哈哈 5.5L 桶装水比价结果去重过程：**

脚本原始输出了 10 条淘宝商品。实际内容如下：
- 商品 #1 和 #2：完全重复（同一推广链接，同一标题，同一价格 ¥71.91）→ 去重保留一条
- 商品 #3、#6、#9：空白条目（标题/价格/店铺全部 N/A）→ 删除
- 商品 #4 和 #5：完全重复（天猫超市，¥71.4）→ 去重保留一条
- 商品 #7 和 #8：完全重复（官方国货甄选，¥36.74）→ 去重保留一条
- 商品 #10：唯一有效商品（¥32.9）

**去重后：** 10条 → **4条有效**

然后 Agent 需计算每条的单价（根据规格解析），排序后给出推荐。
